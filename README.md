Лабораторна робота 1: Структури даних у Python
Практична робота з вивчення вбудованих структур даних у Python: списків, кортежів, словників та множин, а також оцінки алгоритмічної складності (O(n) проти O(1)).
Вимоги:
Python 3.13+
  Як запустити
1. Завантажте файл `main.py`.
2. Відкрийте термінал/командний рядок у папці з файлом.
3. Запустіть скрипт.
